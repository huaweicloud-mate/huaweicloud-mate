# M0 端到端验收场景草案

状态：Draft for M0

以下场景用于冻结行为，不代表首发产品 MCP、region、资源规格或真实测试账号已经绑定。M0 退出前必须由产品与测试责任人补齐真实输入。

## E2E-01：OBS 普通读取与执行前补位

目标：验证无风险普通 read、MCP 优先和执行前 KooCLI 补位。

前置条件：

- OBS list capability 同时映射产品 MCP 和 KooCLI；
- credentials generation 已绑定已验证账号；
- 场景不读取对象内容或其他敏感数据。

步骤与期望：

1. search 返回 `operationKind=read`、空 `riskTags` 和两个执行器；
2. describe 返回输入/输出 schema 与默认 `provider-mcp`；
3. Provider 健康且握手一致时，execute 不要求审批并使用 MCP；
4. Provider 在 execute 开始前不可用时，可选择 KooCLI；
5. 输出通过 schema、大小和脱敏校验，effective account 与当前 generation identity 一致。

## E2E-02：ECS 创建的复合风险审批

目标：验证 write + cost + privileged 的复合风险和可信审批。

前置条件：

- ECS 创建 capability 声明 `operationKind=write`；
- `riskTags` 至少包含 `cost`，配置公网访问时同时包含 `privileged`；
- 当前宿主已绑定固定审批 issuer。

步骤与期望：

1. 首次 execute 只返回 preview、challenge 和本地生成的计费/公网影响摘要；
2. Agent 提交 receipt 或修改参数后重复调用被公开 schema/Router 拒绝；
3. 第二次 execute 只额外提交 `previewId`，Router 内部启动受信 issuer；明确用户操作后签发的 receipt 只经私有 IPC 返回 Router；
4. Router 校验参数、executor、账号代次、scope 和内部 receipt 后，在 dispatch 前原子消费 preview；
5. 执行成功返回 request ID，输出中的管理员密码等敏感路径被清理。

## E2E-03：VPC 公网暴露与执行器锁定

目标：验证 privileged 网络变更、执行前选择 KooCLI 和预览后锁定。

前置条件：

- 安全组规则 capability 可创建 `0.0.0.0/0` 入方向规则；
- 产品 MCP 在首次 execute 前不可用，KooCLI 健康。

步骤与期望：

1. Router 在预览前选择 KooCLI；
2. 摘要明确展示协议、端口、来源 CIDR、目标安全组和公网暴露影响；
3. receipt 绑定 `executor=koocli`；
4. Provider 随后恢复也不得改变已锁定 executor；
5. 修改任一端口、CIDR 或 executor 必须生成新 preview 并重新审批。

## E2E-04：ECS 删除后的结果未知

目标：验证 destructive 操作、preview 单次消费和 `OUTCOME_UNKNOWN` 不自动切换。

前置条件：

- 使用可安全销毁的专用测试 ECS；
- 产品 MCP 和 KooCLI 都声明删除能力。

步骤与期望：

1. 首次 execute 返回包含资源 ID、不可逆影响和关联资源说明的摘要；
2. 可信审批后使用产品 MCP dispatch；
3. 模拟 Provider 已接收请求但响应超时；
4. Router 返回 `OUTCOME_UNKNOWN`、correlation/request ID 和人工查询建议；
5. 不自动切换 KooCLI，不允许复用 preview/receipt；用户需先对账再决定后续动作。

## E2E-05：OBS 对象敏感读取

目标：验证 read 不等于低风险，`sensitive-read` 必须审批。

前置条件：

- 对象读取 capability 标记 `operationKind=read`、`riskTags=[sensitive-read]`；
- output schema、允许内容类型、大小上限和敏感路径已配置。

步骤与期望：

1. 首次 execute 返回对象标识、读取范围和数据进入 Agent 上下文的风险摘要；
2. 未获得可信 receipt 时不得返回对象内容；
3. 审批后只返回 schema 允许且未超过上限的内容；
4. 授权头、签名 URL、session ID、route token 和匹配敏感路径的字段不得进入 Agent 或日志；
5. Provider 返回未知结构、超限内容或不允许的自然语言时返回 `OUTPUT_REJECTED`。
