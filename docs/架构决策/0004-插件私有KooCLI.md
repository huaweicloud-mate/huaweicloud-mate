# ADR-0004：受控复用或私有安装 KooCLI

- 状态：Accepted，已由 ADR-0007 修订
- 日期：2026-07-13

## 决策

Installer 先检测用户预装 KooCLI。版本位于插件兼容范围且 doctor 通过时复用；否则从批准的官方地址下载固定版本、校验 SHA-256，并安装到插件私有用户级目录。

## 原因

- 兼容已有用户环境；
- 避免无条件重复安装；
- 私有固定版本保证插件与 KooCLI 参数、输出契约可复现；
- 不依赖管理员权限和系统 PATH。

## 结果

- 插件维护兼容版本范围、固定版本和 SHA-256 清单；
- 固定版本仍必须执行安装后 doctor 和最小只读 smoke test；
- 不修改用户系统 KooCLI；
- 不在运行期下载 `latest`；
- Agent 只通过受控 Router 调用 KooCLI。
