# ADR-0005：公共 npm 与用户级全局安装

- 状态：Accepted
- 日期：2026-07-13

## 决策

插件通过公共 npm 发布，假定用户已安装 Node.js。默认命令采用 `npx @huaweicloud/agent-plugin install`，在用户级目录安装 Core、KooCLI、Skills 和检测到的 Agent adapters。

## 约束

- 不使用隐式 `postinstall` 修改宿主配置；只有显式 `install/update/uninstall/repair` 命令可产生变更。
- 不需要管理员权限，不修改系统级 PATH。
- 宿主配置变更必须备份、原子写入并可按 install receipt 回滚。
- 首版要求联网直连，不支持离线镜像和 HTTP/HTTPS 代理。
- 首版不支持无桌面 Keyring 的 headless Linux。
