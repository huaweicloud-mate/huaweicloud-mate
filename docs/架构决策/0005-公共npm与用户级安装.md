# ADR-0005：公共 npm 与用户级自动安装

- 状态：Accepted，已由 ADR-0007 精简
- 日期：2026-07-13

## 决策

插件通过公共 npm 发布，假定用户已安装 Node.js。默认入口：

```text
npx @huaweicloud/agent-plugin install
```

Installer 在用户级目录安装 Core、Skills、宿主配置和必要的私有 KooCLI。

## 约束

- 不使用 `postinstall` 修改宿主；
- 首版提供 install、doctor、uninstall；
- 重新运行 install 完成升级；
- 修改宿主配置前备份，失败时恢复；
- 不需要管理员权限，不修改系统 PATH；
- 首版不支持离线、HTTP/HTTPS 代理和 headless Linux；
- 不实现独立 update、repair 或复杂 drift 检测。
