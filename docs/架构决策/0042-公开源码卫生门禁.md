# ADR-0042：公开源码卫生门禁

状态：Accepted
日期：2026-07-15

后续状态：KooCLI 制品已由 ADR-0048 绑定，真实产品 MCP 已后置；源码卫生对正式 endpoint、摘要和本机值的规则继续有效。

## 背景

M4 要求公开仓库不包含凭证、内部 endpoint 或开发机路径。npm pack allowlist 已能阻止源码和工作文件进入 tarball，GitHub gitleaks 也扫描历史 secret，但当前树仍保留已停用的文件规划记录和开发机绝对路径；这不影响运行时，却不满足公开源码本身的发布基线。

## 决策

1. 从当前树删除已停用的 `task_plan.md`、`findings.md`、`progress.md`，保留 Git 历史可追溯性，并将三者加入 `.gitignore`，不重新启用 `planning-with-files`。
2. 正式文档使用仓库根目录或占位用户路径，不记录开发机 workspace、真实用户 profile 或旧 PoC 的本机绝对位置。
3. 新增 `source:check`，只扫描明确受版本控制的源码、文档、测试、workflow、脚本和根元数据；拒绝 symlink、超限或非 UTF-8 文本、开发 workspace 路径、非占位用户 profile、`.internal` endpoint，以及三个停用规划文件重新出现。
4. 错误只报告规则、相对文件和行号，不回显命中内容。示例测试路径只允许固定的 `example`、`fallback` 等占位 profile。
5. CI package job、release candidate workflow 和 `prepublishOnly` 都必须运行 `source:check`。Git 历史 secret 仍由 gitleaks 负责，npm 内容仍由 `pack:check` 独立负责；源码卫生检查不替代两者。

## 结果

- 当前全部受控文本文件通过源码卫生检查，仓库工作文件中不再存在开发 workspace 或当前用户绝对路径。
- 历史提交仍可能包含旧规划记录，因此公开前仍必须保留全历史 gitleaks；本 ADR 不重写 Git 历史。
- 正式产品 MCP endpoint、npm 身份和 KooCLI 制品尚未绑定时不会用示例或本机值填充，继续由 release readiness 门禁拒绝发布。
