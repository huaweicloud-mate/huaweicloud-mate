# ADR-0036：输出凭证模式兜底拒绝

状态：Accepted
日期：2026-07-15

## 背景

Router 已按 capability 的 `sensitivePaths` 执行 JSON Pointer 脱敏，但该机制依赖 capability 作者完整声明路径。若 Provider 的合法 output schema 中意外返回未声明的密钥、Authorization、短会话路由材料、签名 URL 或私钥，schema 校验本身不能阻止它进入 Agent 上下文。

## 决策

1. Router 必须先完成 output schema、JSON 序列化、大小和 provider text 策略校验，再按 `sensitivePaths` 克隆并脱敏，最后扫描剩余输出。
2. 扫描器只匹配明确的凭证字段语义以及 Authorization/安全令牌、签名 URL、SDK/OBS 授权串和 PEM 私钥标记；不以任意高熵字符串、资源 ID、`requestId`、`nextToken` 或签名算法名称推断凭证。
3. 凭证形字段只有在值已完整替换为 `[REDACTED]` 时可以通过。未声明或未完全脱敏的匹配项统一返回 `OUTPUT_REJECTED`。
4. 错误只报告“存在未声明敏感材料”，不得返回命中路径、字段名、值或 Provider 原文。
5. 该兜底不替代 capability 的 output schema 与 `sensitivePaths` 审查；它用于拦截漏声明，不自动扩大公开输出。

## 结果

- Provider 意外返回 AK/SK 字段、route/session token、Authorization、签名 URL 或私钥材料时 fail closed。
- 正式 capability 仍需显式声明所有允许返回但必须脱敏的路径。
- 扫描在已受 `maxBytes` 限制且已克隆为普通 JSON 的结果上迭代执行，不读取 credentials、日志或外部状态。
