# ADR-0001：本地统一 Core 与薄宿主适配

- 状态：Accepted，已由 ADR-0007 精简
- 日期：2026-07-13

## 决策

云资源发现、路由、凭证、风险确认、产品 MCP、KooCLI 和本地日志只在本地统一 Core 实现。

首版宿主适配进一步精简为四份声明式模板，只处理检测、MCP 配置、Skills 安装、验证和卸载，不实现通用 Adapter SPI。

## 原因

- 四类 Agent 共享相同的云资源语义；
- MCP + Agent Skills 是共同扩展面；
- 声明式模板足以覆盖已知四宿主，不需要先构建通用扩展框架；
- 避免安全规则和 Skills 在各宿主复制后漂移。

## 结果

- Core 不依赖任何宿主 Hook；
- 宿主模板不能包含业务逻辑或任意脚本；
- 新增宿主先通过新增受审模板实现，只有出现无法表达的差异后才评估 SPI。
