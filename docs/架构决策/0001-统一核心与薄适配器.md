# ADR-0001：本地统一 Core 与薄宿主适配器

- 状态：Accepted
- 日期：2026-07-13

## 决策

云资源发现、路由、凭证、策略、KooCLI、产品 MCP 客户端和审计只在本地统一 Core 实现。每个 Agent adapter 只处理检测、安装布局、MCP/Skills 注册、验证和卸载。

## 原因

- 首版同时支持四类 Agent；复制业务逻辑会造成安全策略和行为漂移。
- MCP + Agent Skills 是当前四类环境最接近的公共扩展面。
- 新增产品只应更新中心 Registry 与产品 MCP，不应修改每个宿主插件。

## 结果

- Core 必须独立于任何宿主 Hook 工作。
- Adapter 通过能力标记演进，不把品牌名称当作全部抽象。
- 宿主原生插件能力可用于改善安装体验，但不能成为安全边界。
