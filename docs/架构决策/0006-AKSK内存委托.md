# ADR-0006：远程产品 MCP 的强化 AK/SK 内存委托

- 状态：Superseded by ADR-0007
- 日期：2026-07-13

## 历史决策

远程产品 MCP 通过独立凭证控制面接收用户 AK/SK，使用设备 mTLS、产品公钥信封加密和不超过 15 分钟的内存会话。

## 被取代原因

独立控制面、证书签发、KMS/HSM、密钥轮换和 conformance 平台使开源首版依赖大量未交付的官方基础设施。

开源首版改为：

- 用户目录下权限受限的独立 credentials 文件；
- 仅支持一个当前账号；
- Core 通过同域 HTTPS 把 AK/SK 发送到内置官方产品 MCP；
- Provider 只在内存保存最长 15 分钟并返回不透明 session ID；
- 不使用独立控制面、设备 mTLS、信封加密或 KMS/HSM。

该替代方案扩大了对官方产品 MCP 及其 TLS 终止链路的信任，是显式接受的安全取舍。替代决策见 ADR-0007。
