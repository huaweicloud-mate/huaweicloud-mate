# ADR-0006：远程产品 MCP 的 AK/SK 短期内存委托

- 状态：Accepted with mandatory security review
- 日期：2026-07-13

## 决策

远程产品 MCP 通过独立凭证控制面接收用户 AK/SK，并只在短期内存会话中使用。普通 MCP Streamable HTTP 数据面不携带原始凭证。

## 强制控制

- 本地 AK/SK 只保存到 OS Secret Store。
- 控制面使用双向身份认证的 TLS；凭证载荷还要使用 Registry 发布的产品公钥做应用层信封加密。
- session 必须绑定 provider、device、account 和 MCP connection，TTL 不超过 15 分钟。
- Provider 不得把凭证写入日志、trace、数据库、缓存、文件、转储或子进程命令行。
- 过期、断连、重启、撤销、target 变更和账号不匹配必须立即清除会话。
- 每个 Provider 上线前必须通过凭证泄漏扫描、生命周期和账号一致性 conformance tests。

## 风险

永久 SK 会离开用户设备并进入受信任产品 MCP 的内存，风险高于 STS 临时凭证。该决策必须由平台安全负责人批准，且不得扩展到第三方 MCP。
