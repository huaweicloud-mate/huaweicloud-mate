# ADR-0002：自研轻量 Tool Router MCP

- 状态：Accepted，已由 ADR-0007 精简
- 日期：2026-07-13

## 决策

不嵌入或 Fork MetaMCP。自研本地 stdio Tool Router MCP，并固定暴露三个工具：

```text
cloud_capabilities_search
cloud_capability_describe
cloud_action_execute
```

## 原因

- 固定小工具面是首版核心差异；
- MetaMCP 的聚合模型不等同于本项目的渐进式能力披露；
- 本地 Router 还需要统一产品 MCP、KooCLI、凭证、确认和脱敏。

## 结果

- 删除语义冲突的 `mcp_provision`；
- 禁止任意代码执行型 `mcp_execute`；
- status 由 CLI doctor/auth 命令承担；
- plan 合并到 execute 的两阶段确认协议。
