# ADR-0002：自研轻量 Tool Router MCP

- 状态：Accepted
- 日期：2026-07-13

## 决策

不嵌入或 Fork MetaMCP。仅借鉴 namespace、catalog、middleware 思路，自研本地 stdio Tool Router MCP，并向 Agent 暴露固定小工具面。

## 原因

- MetaMCP 当前主要聚合 namespace 内工具，公开模型不等同于固定 meta-tools 的延迟发现。
- 桌面插件不应强制依赖 Docker/PostgreSQL 或远端 MetaMCP gateway。
- 本项目必须统一执行 KooCLI、凭证、审批和审计，边界超出普通 MCP 聚合器。

## 结果

- 删除含义冲突的 `mcp_provision`。
- 禁止任意代码执行型 `mcp_execute`。
- Router 以 search/describe/status/plan/execute 五类能力实现渐进式披露。
