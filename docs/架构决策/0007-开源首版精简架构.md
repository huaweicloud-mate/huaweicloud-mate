# ADR-0007：开源首版精简架构

- 状态：Accepted
- 日期：2026-07-13

## 背景

Proposed v0.2 同时设计了动态签名 Registry、独立凭证控制面、mTLS、信封加密、KMS/HSM、通用 Adapter SPI、Policy Engine 和分布式审计。该方案适合官方平台化演进，但作为首个开源版本交付过重。

用户仍要求首版具备：

- 四类 Agent 自动安装；
- 产品 MCP 与 KooCLI；
- 创建、修改、删除、IAM、网络和计费操作；
- 用户只需提供 AK/SK；
- 固定小工具面。

因此精简不能依赖缩小用户、宿主或操作范围，而要删除企业级治理和尚未必要的抽象。

## 决策

1. 使用单一 TypeScript npm package。
2. 本地 stdio Router 只暴露 search、describe、execute。
3. plan 合并到 execute 的两阶段确认协议。
4. Provider 和 capability 元数据静态随 npm 发布，不建设动态 Registry。
5. 用户显式执行器优先；默认产品 MCP 优先，未覆盖时 KooCLI 补位。
6. 确认后或执行开始后锁定 executor，失败不自动切换。
7. 产品 MCP 在同域 HTTPS credential session 中接收 AK/SK，内存保存最长 15 分钟。
8. 本地使用权限受限的 credentials 文件，只支持一个当前账号。
9. KooCLI 优先复用兼容预装版本，否则安装私有固定版本并 doctor。
10. 四宿主使用声明式模板，不设计通用 Adapter SPI。
11. 只保留 Router 固定风险门禁和本地 JSONL 日志。

## 明确删除

- 动态 Registry、签名、吊销和远程 denylist；
- 第三方或社区 Provider；
- 独立凭证控制面、设备 mTLS、信封加密和 KMS/HSM；
- OS Keyring、多账号 target；
- 通用 Policy Engine、企业策略中心和集中审计；
- 独立 update/repair 与复杂 drift 检测；
- 多 package 控制平面。

## 安全取舍

凭证文件是受权限保护的明文文件，官方产品 MCP 可以在内存中接触明文 AK/SK。如果本机账号、Provider 或其可信 HTTPS 终止链路被攻陷，AK/SK 可能泄漏。首版通过文件权限、同源 HTTPS、短 TTL、禁止持久化、日志脱敏和可覆盖轮换降低风险，但不能消除风险。

该协议只适用于 npm 内置的官方产品 MCP。

## 影响

- 开源仓库可以独立交付本地核心，不再阻塞于证书、KMS 和 Registry 平台；
- 首版模块和测试面显著缩小；
- Provider 更新需要发布新的 npm 版本；
- 多账号、企业治理、动态 Provider 和更强凭证保护留待后续版本；
- ADR-0003 和 ADR-0006 被本决策取代；
- ADR-0001、ADR-0002、ADR-0004 和 ADR-0005 按本决策修订。
