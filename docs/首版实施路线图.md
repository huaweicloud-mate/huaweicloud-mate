# 首版实施路线图

状态：Proposed

## M0：契约冻结与技术验证

交付：

- Router tool schema v1；
- Capability schema v1；
- Provider Manifest schema v1；
- Adapter SPI v1；
- Policy/risk/error model v1；
- mTLS + envelope encryption 凭证会话 PoC；
- 94+ 工具规模下的上下文、发现准确率和延迟基准。

退出标准：

- 平台安全团队接受 AK/SK 短期内存委托设计；
- Registry、证书签发和 Provider encryption key 的责任团队明确；
- 删除 `mcp_provision` 和任意代码 `mcp_execute` 的接口决策冻结。

## M1：公共 npm Installer 与本地 Core

交付：

- TypeScript monorepo、CI、公共 npm 发布流水线；
- `hcloud-agent install/update/uninstall/doctor`；
- user-scope 目录、receipt、原子安装和回滚；
- Windows/macOS/Linux desktop Secret Store；
- KooCLI 下载、SHA-256、私有安装、版本锁定和回滚；
- target 管理与本地审计。

退出标准：

- 五个平台组合完成无管理员权限安装；
- 不支持环境由 doctor 明确拦截；
- KooCLI 在 OBS/ECS/VPC/IAM 完成只读 smoke tests；
- AK/SK 未进入命令行、文件或日志。

## M2：Tool Router、Catalog 与 Policy

交付：

- 五个固定 Router tools；
- capability search/describe/index cache；
- MCP/KooCLI peer executor model；
- plan token、风险分类、确认与结果未知处理；
- Registry 签名、缓存、过期和吊销；
- KooCLI capability adapter。

退出标准：

- Agent 工具面保持固定；
- 四产品能力可搜索/描述；
- read `auto` 有确定性审计；
- 副作用执行器锁定且无自动切换。

## M3：远程 Provider 安全链路

交付：

- 设备身份引导和短期 mTLS 凭证；
- Provider 公钥信封加密；
- credential session create/bind/revoke；
- account identity proof；
- Provider conformance runner；
- 至少一个正式产品 MCP 接入。

退出标准：

- 凭证泄漏扫描为零；
- 断连、过期、重启、撤销、错账号全部拒绝动作；
- endpoint/key rotation/Registry revoke 演练通过；
- 未通过 Provider 自动降级为 discovery-only。

## M4：四类 Agent Adapter

交付顺序建议：

1. Codex；
2. Claude Code；
3. OpenCode；
4. 华为云码道。

每个 Adapter 都交付：

- user-scope install/update/repair/uninstall；
- MCP 配置与 canonical Skills；
- install receipt 和 drift 检测；
- 宿主版本兼容矩阵；
- Router/KooCLI/远程 MCP 端到端测试。

退出标准：四类 Agent 在受支持桌面 OS 上完成相同场景并产生一致审计语义。

## M5：首版产品覆盖与发布加固

产品范围：OBS、ECS、VPC、IAM。

- 产品 MCP 已上线且通过 conformance 时，提供 MCP + KooCLI 双路径；
- 产品 MCP 未上线时，允许 KooCLI 满足首版覆盖；
- IAM、网络公网暴露、删除、计费动作执行专项红队测试；
- 完成 SBOM、许可证、漏洞、secret、npm provenance 和回滚演练；
- 发布安装、升级、卸载、故障恢复和 Provider 接入文档。

退出标准：总体架构文档中的首版验收基线全部通过。

## 测试矩阵

平台：

- Windows amd64；
- Linux amd64/arm64（有桌面 Secret Service）；
- macOS amd64/arm64。

宿主：

- OpenCode；
- Claude Code；
- Codex；
- 华为云码道。

执行器：

- KooCLI；
- 至少一个正式远程产品 MCP；
- discovery-only Provider；
- Provider unavailable/revoked。

风险：

- read；
- write；
- destructive；
- privileged；
- cost；
- outcome unknown。

## 外部依赖

- 公共 npm scope 和发布身份；
- KooCLI 官方固定版本下载清单与校验维护；
- Registry 签名密钥托管；
- 设备 mTLS 证书注册/签发服务；
- 产品 MCP credential encryption key 管理；
- 产品团队 Provider owner/on-call；
- 平台安全负责人对永久 AK/SK 内存委托的批准。

## 不进入首版

- 离线安装和企业镜像；
- HTTP/HTTPS 代理；
- headless Linux secret fallback；
- Agent Space 等纯云端宿主；
- 第三方 MCP 的 AK/SK 委托；
- 任意代码工作流执行器；
- 常驻本地 daemon；
- 全量 OpenAPI 在 Agent 侧展开为工具。
